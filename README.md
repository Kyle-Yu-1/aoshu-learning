# 奥数学堂 · 小升初奥数智能学习平台

一个面向小升初的奥数学习网站：知识体系 + 交互式教材 + 智能刷题 + 错题本 + 学情分析，纯静态实现，数据保存在浏览器本地。

## 功能

| 模块 | 说明 |
|---|---|
| 🏠 概览 | 七大模块知识体系树、统计卡片（正确率/连续天数/待复习/错题数）、今日推荐 |
| 📖 知识学习 | 7 大模块 26 个知识点、101 个教材章节（要点/易错点/思维方法/例题），可折叠阅读、标记薄弱章节 |
| 🎯 智能刷题 | ①算法推荐：SM-2 记忆曲线间隔重复 + 知识体系进度 + 薄弱环节加权 + 难度适配 + 学习计划配额；②自主选题：按模块/知识点/难度/错题组卷 |
| 📚 题库 | 140 道精选真题风格题目（7 模块 × 20 题），搜索、筛选、查看解析、加入今日练习 |
| ❌ 错题本 | 按错误次数排序、重做、连续做对 2 次自动移出 |
| 📊 学情分析 | 折线图（每日刷题量/正确率）、条形图（学习进度/错误率）、雷达图（七大模块能力值）、知识点强弱明细、**阿基米德提问式诊断**（定位杠杆点 → 引导提问 → 一键生成 7 天优化计划） |
| ⚙️ 设置 | 每天刷题数、算法探索度、数据导出/导入/清空 |

## 刷题算法说明

每道题综合打分：到期复习（逾期越久越急，权重最高）+ 错题加成 + 薄弱知识点加权 + 章节学习进度匹配（前置未学不推荐）+ 新题探索分 + 难度适配 + 优化计划配额 + 随机微扰。

答题后按 SM-2 间隔重复更新：复习间隔 1 → 3 → 7 → 16 → 35 天递增，答错重置并进入错题本。

## 本地运行

直接双击 `index.html`，或：

```bash
npx serve .
# 或任意静态服务器，如 python -m http.server 8123
```

数据存于浏览器 localStorage（`aoshu_state_v1`），换设备请用"设置 → 导出/导入"。

## 技术栈

原生 HTML/CSS/JS + ECharts（本地化在 `js/vendor/`），无构建步骤、无后端。

```

```
