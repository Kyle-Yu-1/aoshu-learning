# 奥数学堂 · 小升初奥数智能学习平台

一个面向小升初的奥数学习网站：知识体系 + 交互式教材 + 智能刷题 + 错题本 + 学情分析，纯静态实现，数据保存在浏览器本地。

## 功能

| 模块 | 说明 |
|---|---|
| 🏠 概览 | 七大模块知识体系树、统计卡片（正确率/连续天数/待复习/错题数）、今日推荐 |
| 📖 知识学习 | 7 大模块 26 个知识点、260 个讲解章节 + 78 道例题（每讲 10 段式：导学/核心概念/公式速记/方法技巧/三梯度例题/易错警示/名师口诀/真题链接），可折叠阅读、标记薄弱章节 |
| 🎯 智能刷题 | ①算法推荐：SM-2 记忆曲线间隔重复 + 知识体系进度 + 薄弱环节加权 + 难度适配 + 学习计划配额；②自主选题：按模块/知识点/难度/错题组卷 |
| 📚 题库 | 666 道精选真题风格题目，按 7 大模块 26 个知识点归类并标注逐讲来源，搜索、筛选、查看解析、加入今日练习 |
| ❌ 错题本 | 按错误次数排序、重做、连续做对 2 次自动移出 |
| 📊 学情分析 | 折线图（每日刷题量/正确率）、条形图（学习进度/错误率）、雷达图（七大模块能力值）、知识点强弱明细、**阿基米德提问式诊断**（定位杠杆点 → 引导提问 → 一键生成 7 天优化计划） |
| ⚙️ 设置 | 每天刷题数、算法探索度、数据导出/导入/清空 |

## 刷题算法说明

每道题综合打分：到期复习（逾期越久越急，权重最高）+ 错题加成 + 薄弱知识点加权 + 章节学习进度匹配（前置未学不推荐）+ 新题探索分 + 难度适配 + 优化计划配额 + 随机微扰。

答题后按 SM-2 间隔重复更新：复习间隔 1 → 3 → 7 → 16 → 35 天递增，答错重置并进入错题本。

## 本地运行

直接双击 `index.html`，或：

```bash
npx serve .
# 或任意静态服务器，如 python -m http.server 8123
```

数据存于浏览器 localStorage（`aoshu_state_v1`），换设备请用"设置 → 导出/导入"。

## 技术栈

原生 HTML/CSS/JS + ECharts（本地化在 `js/vendor/`），无构建步骤、无后端。

## 题库来源与参考体系

- **学而思秘籍《小学数学思维培养》1-12 级**：小学奥数十二级体系（计算、整数、图形、应用、行程、组合、计数、综合八大问题），覆盖其全部核心专题——分数裂项（11级）、燕尾/鸟头/蝴蝶/沙漏模型（9-10级）、韩信点兵/同余（11级）、电梯与发车（9级）、切片染色（11级）、勾股弦图（10级）、必胜策略与棋盘数学（9级）、杨辉三角数表（10级）、旋转与轨迹/复合图形分拆/算两次（12级）等。
- **学而思双减前教材体系**：原学而思培优/网校讲义主线（整数巧算、等差数列、和差倍、鸡兔同笼、盈亏、牛吃草、浓度、工程、行程十六讲、五大模型、数字谜、数阵图等），对应本题库各模块高频题。
- **小学数学竞赛**：华杯赛（数论/计数/几何/组合侧重，含构造论证）、迎春杯（数字谜、数阵、逻辑）、希望杯（课内延伸）。
- **小升初名校真题**：人大附早培（最大公约数最值、容斥计数）、江苏/常州等名校卷（工程问题、行程、经济分段计价）、68 所名校专练（分数应用题、工程休息请假型、经济问题等 20 个专项）。
- **B 站主流课程**：乐乐课堂·天天练、数理研习社《小升初精讲》、七大专题课、名校 178 讲等课程题型归纳。
