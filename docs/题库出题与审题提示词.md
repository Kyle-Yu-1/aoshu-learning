# 题库出题与审题提示词（Prompt）

> 用途：本项目所有新增/修改题目的出题与审题基准。每道题入库前，必须逐条通过本清单。
> 版本：v1.0（2026-11-23）　角色：资深小升初命题人 + 题库审校

---

## 一、出题硬性规范

1. **无图可解（第一铁律）**：网站题目只有文字与选项，没有任何插图。题干必须用文字完整交代图形的位置、大小、关系（点、边、角、圆心、比例），或把题设计成概念/方法题。禁止出现"如图""下图阴影"等依赖配图的表述。
2. **数据自洽**：所有已知条件必须足够推出唯一答案；禁止"条件不足"却要求具体数值的题（条件不足题必须把答案设为"无法确定"并说明）。
3. **答案唯一**：填空题答案允许多个等价写法时用 `|` 分隔（如 `4.5|9/2`）；选择题 4 个选项必须互斥、且恰有一个正确。
4. **答案格式**：百分数题问"百分之几"、答案写数字（如 19）；比写 `4:1`；分数写最简分数；多答案用 `|`；单位放题干不放答案。
5. **解析讲"为什么"**：每步给出依据（公式/性质/原因），不跳步；难题给 `hint`（一句话提示，不剧透答案）。
6. **来源标注**：每题必须在 `tools/build-bank.js` 的 Q_SRC 中标注到具体讲次/真题出处（如"学而思秘籍10级·第2讲燕尾模型"）。
7. **难度分级**：diff 1=课内基础、2=培优入门、3=名校面测/分班考、4=杯赛/压轴。
8. **不超纲**：只用小学工具（线段图、假设、枚举、比例、少量字母设数），不用初中以上概念。

## 二、审题十大检查项（逐题打勾）

- [ ] 1. 无图可解：题干文字已完整描述图形/表格/排列
- [ ] 2. 条件充分：已知量能推出唯一答案（或明示"无法确定"）
- [ ] 3. 答案与解析一致：解析推得的正是答案项
- [ ] 4. 选择题选项互斥、恰一个正确、答案文本与选项完全一致
- [ ] 5. 数据无矛盾（如"贯穿"与表面积变化结论吻合）
- [ ] 6. 计算经程序/手算双重验算
- [ ] 7. 与题库现有题目不重复（同题不同数据也算重复）
- [ ] 8. 知识点（topic）归类正确、来源标注具体
- [ ] 9. 提示语不剧透最终答案
- [ ] 10. 无歧义表述：单位、π 取值、取整方向均已写明

## 三、易踩的坑（真实案例）

| 坑 | 案例 | 修正 |
|---|---|---|
| 依赖图 | "求下图阴影面积" | 改为文字描述图形或用方法题替代 |
| 答案解析打架 | 凹字形问面积却答"平移法"（平移法是周长技巧） | 面积→添补法 |
| 数据与结论矛盾 | "贯穿挖洞"表面积应 +10，却写 +4 | 改为"不贯穿挖 1 层"+4，或改选项 |
| 题干歧义 | "切成两半后拼成长方体" | 改"切成两个半圆柱，每个切面=直径×高" |
| 概念不定义 | "两个月牙面积之和" | 题干补定义："直角边半圆与斜边半圆之间的部分" |
| 周期取位 | 指数÷周期余 0 | 取周期末位，不是第 0 位 |

## 四、入库流程

1. 在 `js/data-questions.js` 末尾 `];` 前追加题目（用 tools 脚本序列化，避免引号问题）；
2. 在 `tools/build-bank.js` 补 Q_SRC 来源映射；
3. 运行 `node tools/build-bank.js` 重新生成 `题库/` 与 `js/data-source.js`；
4. `node --check` 全部 JS + 程序验算新题答案；
5. 提交 → `node tools/push-via-api.js` 部署 → 线上验证。
