# 裂项法

> 所属模块：计算｜题数：15
>
> 来源体系：学而思秘籍11级·第1讲分数裂项；《奥数教程》六年级第1、4讲；《高思导引》六年级第1讲分数数列计算
>
> 核心思维：拆分重组思想。看到分母是两个连续/相差固定整数的乘积，就考虑裂项。

---

## 第 30 题（题库编号 #6，难度 ★★☆☆☆）

**题干：** 计算：1/(1×2) + 1/(2×3) + … + 1/(99×100) = ?

**来源：** 学而思秘籍11级·第1讲分数裂项；《奥数教程》六年级第1、4讲；《高思导引》六年级第1讲分数数列计算

**答案：** 99/100

**解析：** = (1-1/2)+(1/2-1/3)+…+(1/99-1/100) = 1-1/100 = 99/100。相邻抵消。

**提示：** 裂差：1/[n(n+1)] = 1/n - 1/(n+1)。

## 第 32 题（题库编号 #7，难度 ★★★☆☆）

**题干：** 计算：1/(1×3) + 1/(3×5) + … + 1/(99×101) = ?

**来源：** 学而思秘籍11级·第1讲分数裂项；《奥数教程》六年级第1、4讲；《高思导引》六年级第1讲分数数列计算

**答案：** 50/101

**解析：** 每项 = ½(1/(2n-1) - 1/(2n+1))，提出 1/2 后抵消：½×(1 - 1/101) = 50/101。

**提示：** 间隔为 2，裂项后要乘 1/2。

## 第 33 题（题库编号 #8，难度 ★★★☆☆）

**题干：** 计算：1×2 + 2×3 + 3×4 + … + 99×100 = ?

**来源：** 学而思秘籍11级·第1讲分数裂项；《奥数教程》六年级第1、4讲；《高思导引》六年级第1讲分数数列计算

**答案：** 333300

**解析：** 整数裂项：n(n+1) = [n(n+1)(n+2)-(n-1)n(n+1)]/3，和 = 99×100×101/3 = 333300。

**提示：** n(n+1)(n+2) 三连乘消去。

## 第 37 题（题库编号 #501，难度 ★★★☆☆）

**题干：** 化简繁分数：1 ÷ (1 + 1 ÷ (1 + 1/2))。

**来源：** 《奥数教程》六年级·第4讲繁分数｜学而思秘籍11级·第1讲分数裂项；《奥数教程》六年级第1、4讲；《高思导引》六年级第1讲分数数列计算

**答案：** 3/5

**解析：** 从最底层回代：1+1/2=3/2；1÷(3/2)=2/3；1+2/3=5/3；1÷(5/3)=3/5。

**提示：** 由底向上逐层化简。

## 第 41 题（题库编号 #432，难度 ★★★★☆）

**题干：** 计算：1/(1+2) + 1/(1+2+3) + 1/(1+2+3+4) + … + 1/(1+2+…+100) = ?（华杯赛真题风格）

**选项：**
- A. 99/101
- B. 99/100
- C. 1
- D. 198/101

**来源：** 华杯赛真题风格｜学而思秘籍11级·第1讲分数裂项；《奥数教程》六年级第1、4讲；《高思导引》六年级第1讲分数数列计算

**答案：** 99/101

**解析：** 1/(1+2+…+n)=2/[n(n+1)]=2(1/n−1/(n+1))。原式=2×(1/2−1/3+1/3−1/4+…+1/100−1/101)=2×(1/2−1/101)=99/101。

**提示：** 2/n(n+1) 裂项。

## 第 44 题（题库编号 #577，难度 ★★★★☆）

**题干：** 计算 1×3 + 2×4 + 3×5 + … + 9×11。

**来源：** 学而思秘籍11级·第6讲整数裂项与通项归纳｜学而思秘籍11级·第1讲分数裂项；《奥数教程》六年级第1、4讲；《高思导引》六年级第1讲分数数列计算

**答案：** 375

**解析：** 通项 n(n+2) = n²+2n：平方和 9×10×19÷6 = 285，加上 2×(1+2+…+9) = 90，共 375。

**提示：** 通项归纳再拆公式。
